# FastFood POS

A simple desktop Point of Sale (POS) system for a fast-food store, built with Python, Tkinter, and SQLite.

## Features

- Fast-food menu with categories and prices
- Add items to an order
- Increase/decrease quantities and remove items
- Automatic 5% tax calculation
- Cash, Card, and Mobile Wallet payment selection
- Completed sales stored in SQLite
- Sale items stored for future reporting/receipts

## Run

Python 3.10+ is recommended. Tkinter and SQLite are part of the Python standard library on most desktop Python installations.

```bash
python app.py
```

The local `pos.db` database is created automatically on first run.
